# 🌃 NIGHT CITY NEON HUB (ip_tv-neon v0.8.2)

Ультимативный TUI (Terminal User Interface) медиа-хаб для просмотра IPTV и прослушивания радио, радикально оптимизированный под **Intel Haswell (Iris Pro 5200)**, **CachyOS** и терминал **Kitty**.

## 🚀 Основные возможности

### 📺 IPTV & EPG (epg.one)
- **Turbo-Search:** Мгновенный поиск по каналам (просто начните печатать). Находит даже сложные префиксы типа `VF` или `BCU`.
- **O(1) EPG Mapping:** Интеллектуальное сопоставление программы передач по `tvg-id`, оригинальному и нормализованному именам.
- **Timeline в списках:** Прямо в списке каналов отображается прогресс текущей передачи `[███░░░]`.
- **Schedule Detail:** Подробное расписание с описаниями и поддержкой архивов.

### 📻 RADIO RECORD
- **Live Metadata:** Отображение текущего трека (**Исполнитель — Песня**) в реальном времени прямо в списке станций.
- **Smart Minimize:** При выборе радио хаб автоматически сворачивается, оставляя управление в Waybar.

### ⏪ TimeShift (Catch-up / Архивы)
- **Автоматическое определение:** Хаб распознает теги `tvg-rec` и `catchup-days` в плейлисте.
- **Просмотр:** В меню **Detail** выберите любую прошлую передачу (помечена `⏪`) и нажмите Enter. Хаб автоматически сгенерирует URL для архива.

### 📂 Local Scanner
- Сканирует `~/Downloads`, `~/Videos` и `/media` на наличие плейлистов.
- Позволяет мгновенно переключаться между провайдерами.

## 🎮 Управление (Keyboard Shortcuts)

### Внутри Хаба (TUI):
- **Стрелки / Home / End**: Навигация по спискам.
- **Буквы/Цифры**: Мгновенный поиск.
- **Enter**: Выбор / Запуск (в Detail view: **Live** или **Archive**).
- **Esc**: Назад.
- **Ctrl + f**: Добавить в избранное (скоро).
- **h**: Быстрый переход к истории просмотров.
- **r**: Быстрый переход к Радио.
- **Ctrl + C**: Выход.

## 📦 Установка и обновление

1. **Сборка проекта:**
   ```bash
   cd ~/Git/ip_tv-neon
   cargo build --release
   ```
2. **Системная установка:**
   ```bash
   cp target/release/ip_tv-neon ~/.local/bin/ip_tv
   ```

## 📝 Файлы конфигурации
- **Хаб:** `~/.config/neon-iptv/config.json`
- **Кэш данных:** `~/.cache/neon-iptv/data.bin` (Binary Serialization)
- **Плеер:** `~/.config/mpv/mpv.conf`
