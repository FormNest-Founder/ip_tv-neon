# 🌃 NIGHT CITY NEON HUB (ip_tv-neon)

Ультимативный TUI (Terminal User Interface) медиа-хаб для просмотра IPTV и прослушивания радио, оптимизированный под **CachyOS** и терминал **Kitty**. 

Построен на Rust для максимальной производительности на железе уровня Intel Haswell.

## 🚀 Основные возможности

### 📺 IPTV & EPG
- **Мгновенный EPG в списке:** При входе в категорию программа автоматически подтягивает расписание для всех каналов.
- **Индикация времени:** Возле каждого канала отображается:
  - Название текущей передачи.
  - Сколько минут осталось до конца (`left`).
  - Название следующей передачи и время её начала.
- **Информативный MPV:** Текущая программа передается в плеер и отображается в заголовке и OSD (`force-media-title`).

### 📻 RADIO
- **Фоновое воспроизведение:** При запуске радио меню остается открытым, позволяя переключать станции, не прерывая поток.
- **Управление:** Возможность мгновенно остановить звук через пункт `STOP ALL`.

### ⚙️ Гибкая настройка
- **Динамические плейлисты:** Изменение URL плейлиста и EPG прямо в меню `SETTINGS`.
- **Конфигурация:** Настройки сохраняются в `~/.config/neon-iptv/config.json`.
- **Системный MPV:** Бинарник использует ваш системный `mpv.conf`, обеспечивая привычное управление и качество видео.

### 🎮 UX & Навигация
- **Esc-Back:** Поддержка клавиши `Esc` для возврата на предыдущий уровень меню.
- **Поиск:** Встроенный Fuzzy-поиск по каналам — просто начните вводить название.
- **Автономность:** Плеер запускается в независимой сессии (`setsid`), терминал с меню автоматически закрывается при просмотре ТВ.

## 🛠️ Технический стек
- **Язык:** Rust (Edition 2024).
- **Плеер:** MPV (с поддержкой аппаратного ускорения VA-API).
- **Библиотеки:** 
  - `dialoguer` & `console` для интерфейса.
  - `tokio` & `reqwest` для асинхронной сети.
  - `quick-xml` для быстрого парсинга EPG.
  - `chrono` для синхронизации времени.

## 📦 Установка и запуск

1. **Сборка:**
   ```bash
   cd ip_tv-neon
   cargo build --release
   ```
2. **Обновление кэша:**
   ```bash
   ./target/release/ip_tv-neon update
   ```
3. **Запуск:**
   ```bash
   ./target/release/ip_tv-neon
   ```

## 📝 Конфигурация
Файл находится по пути: `~/.config/neon-iptv/config.json`
По умолчанию используются оптимизированные под СНГ плейлисты и серверы EPG.
