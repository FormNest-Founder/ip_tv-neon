# 🌃 NIGHT CITY NEON HUB (ip_tv-neon v0.7.1)

Ультимативный TUI (Terminal User Interface) медиа-хаб для просмотра IPTV и прослушивания радио, радикально оптимизированный под **Intel Haswell (Iris Pro 5200)**, **CachyOS** и терминал **Kitty**.

## 🚀 Основные возможности

### 📺 IPTV & EPG (epg.one)
- **Turbo-Search:** Мгновенный поиск по каналам (просто начните печатать). Находит даже сложные префиксы типа `VF` или `BCU`.
- **O(1) EPG Mapping:** Интеллектуальное сопоставление программы передач по `tvg-id`, оригинальному и нормализованному именам.
- **Timeline в списках:** Прямо в списке каналов отображается `NOW: Название передачи`.
- **Schedule Detail:** Подробное расписание на 8 передач вперед с описаниями.

### 📻 RADIO RECORD
- **Live Metadata:** Отображение текущего трека (**Исполнитель — Песня**) в реальном времени прямо в списке станций.
- **Smart Minimize:** При выборе радио хаб автоматически сворачивается, оставляя управление в системном трее (`ksni`).

### ⏪ TimeShift (Catch-up / Архивы)
- **Автоматическое определение:** Хаб распознает теги `tvg-rec` и `catchup-days` в плейлисте.
- **Индикация:** Каналы с архивом помечены `[DVR: 7d]` в детальном просмотре.
- **Просмотр:** В меню **Detail** выберите любую прошлую передачу (помечена `⏪`) и нажмите Enter. Хаб сгенерирует ссылку на архив и запустит воспроизведение.

### 📂 Local Scanner
- Сканирует папку `~/Downloads` на наличие `.m3u` и `.m3u8` файлов.
- Позволяет открывать и проигрывать локальные плейлисты одной кнопкой.

## 🎮 Управление (Keyboard Shortcuts)

### Внутри Хаба (TUI):
- **Стрелки / Home / End**: Навигация по спискам.
- **Буквы/Цифры**: Мгновенный поиск.
- **Enter**: Выбор / Запуск (в Detail view: **Live** или **Archive**).
- **Esc**: Назад.
- **Ctrl + f**: Добавить в избранное.
- **h**: Быстрый переход к истории просмотров.
- **i**: Быстрый переход к категориям.
- **r**: Быстрый переход к Радио.
- **Ctrl + C**: Выход.

### Внутри Плеера (MPV):
- **n**: Включить **RETRO-FIX** (для мыльных старых записей).
- **N (Shift + n)**: Вернуть стандартную резкость (**CAS**).
- **Ctrl + n**: Выключить все AI-шейдеры.
- **i**, затем **2**: Показать детальную инфо о работающих шейдерах.
- **f**: Полноэкранный режим.
- **m**: Выключить звук.

## 📦 Установка и обновление

1. **Сборка проекта:**
   ```bash
   cd ~/Git/ip_tv-neon
   cargo build --release
   ```
2. **Системная установка:**
   ```bash
   sudo cp target/release/ip_tv-neon /usr/bin/ip_tv
   ```
3. **Обновление базы данных (EPG + Radio):**
   Выберите пункт **🔄 UPDATE** в главном меню или запустите:
   ```bash
   ip_tv update
   ```

## 📝 Файлы конфигурации
- **Хаб:** `~/.config/neon-iptv/config.json` (URL плейлиста и EPG).
- **Плеер:** `~/.config/mpv/mpv.conf` (Шейдеры и рендеринг).
- **Бинды:** `~/.config/mpv/input.conf` (Управление AI-режимами).
